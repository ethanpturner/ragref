# Joint integration timeline

The integration proceeds in three milestones agreed by both parties.

Milestone one: read endpoints connected in both test environments, with reconciliation running
and reporting. Owned jointly by the two integration leads.

Milestone two: production connection for a single pilot tenant, with a rollback plan rehearsed
before cutover.

Milestone three: all tenants connected and the legacy export retired. Retirement waits for two
clean reconciliation cycles.
